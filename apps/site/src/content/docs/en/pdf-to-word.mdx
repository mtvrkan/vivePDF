To convert a PDF to Word, open **Tools › Convert**, choose **PDF → Word** on the left, add your file and click **Convert**. The result is a .docx file you can edit in Word or LibreOffice, with its tables and pictures carried over.

<Steps>
1. Open **Tools › Convert** and choose **PDF → Word** in the list on the left.
2. Choose the PDF, or drag it onto the window.
3. If you only need some pages, type them in the **Pages** box, such as `1-3, 5`; leave it empty to convert every page.
4. Click **Convert**.
</Steps>

<Shot src="en/word-1" alt="PDF → Word selected in the Convert tool: agreement.pdf, the Pages box and the output file" />

The new .docx file appears in the result panel. The button next to it opens the file in its default app, and the folder icon shows it in Finder or Explorer.

<Shot src="en/word-2" alt="Conversion finished: 1 file and agreement.docx in the panel on the right" />

With **Move repeated headers and footers into Word** on, text repeated at the top or bottom of most pages becomes Word's own header and footer instead of body text, and page numbers turn into Word's page number field.

<Callout type="warn" title="Scanned PDFs">
The pages of a scanned document are pictures; with no selectable text in them, Word gets only pictures too. Recognise the text with [OCR](/en/docs/ocr/) first, then convert to Word.
</Callout>

The same tool converts PDFs to Excel, PowerPoint, pictures, text and HTML. Every format is listed on the [Convert files](/en/docs/convert/) page.
