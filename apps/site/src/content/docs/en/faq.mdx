faq:
  - q: "Is vivePDF free?"
    a: "Yes, vivePDF is completely free. Every tool is included, and there are no paid tiers, accounts or usage limits."
  - q: "Are my files uploaded to a server?"
    a: "No. Your documents, passwords and certificates never leave your computer; all the work happens on it. Help › Privacy lists every case in which the app goes online."
  - q: "Does it work without an internet connection?"
    a: "Yes, the tools do not need an internet connection. Only things such as update checks, downloading language packs or turning a web page into a PDF go online. Offline mode in Settings › Web stops all of those connections with one switch."
  - q: "Which operating systems does it run on?"
    a: "A ready-made installer is available for Windows 10 and Windows 11 (64-bit). The macOS version is being prepared for Macs with Apple silicon on macOS 14 Sonoma or later. There is no Linux package yet, but you can build vivePDF from source."
  - q: "Is vivePDF open source?"
    a: "Yes. All of the source code is published on GitHub under the AGPL-3.0 licence. You can read it, build it yourself and change it."
  - q: "Can I edit the existing text in a PDF?"
    a: "Yes. In Edit › Edit text, click a run of text on the page to change its text, size or colour. The new text is written in the document's own font at the same size; if it does not fit, it is shrunk and you are told."
  - q: "Can I sign a PDF with a digital certificate?"
    a: "Yes. Tools › Sign applies a PAdES signature with your .p12 or .pfx certificate and also verifies signed files. If you have no certificate, vivePDF can create a self-signed one; it proves the document has not changed, but legal validity needs a qualified e-signature."
  - q: "Which languages can OCR read?"
    a: "Turkish and English come with the app. Packs for about 40 languages can be downloaded in Settings › Tools › OCR language packs; each is downloaded once and then works offline."
  - q: "How do I update vivePDF?"
    a: "The app checks for new versions itself and asks before downloading anything. To check by hand, click Check for updates in Settings › Updates, then choose Download and install and Restart."
  - q: "Does it collect usage data or telemetry?"
    a: "No. vivePDF collects no usage data, identifiers or crash reports, and it does not ask you to create an account. Bug reports are never sent automatically either."
  - q: "Where do I report a bug?"
    a: "Help › Report a bug opens a report window where you can copy the report, save it to a file or open it as a prefilled GitHub issue in your browser. Nothing is sent automatically, and you can also go straight to the Issues section of the vivePDF repository on GitHub."
  - q: "Which languages is the interface available in?"
    a: "The interface comes in eight languages: Turkish, English, German, French, Spanish, Italian, Brazilian Portuguese and Arabic. Arabic is shown right to left."
