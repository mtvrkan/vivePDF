vivePDF documentation

Documentation

Everything vivePDF does, step by step, from installing it to presenting. Written with the app's own menu names, from the same help topics that work offline in the app.

Getting started

  • InstallationHow to install vivePDF on Windows 10/11 and macOS 14+, get past the SmartScreen and Gatekeeper warnings, receive updates and uninstall it.
  • InterfaceA tour of vivePDF's top bar, Tools menu, command palette, tabs, tab groups, windows and the side panels in the Viewer.

Working with documents

  • Open and read a PDFHow to open documents in vivePDF, move between pages, search the text, zoom, change the page display, split the window and read comfortably.
  • Organise pagesHow to reorder, rotate, delete, insert, extract and split PDF pages with the vivePDF page organizer, and what happens to the original file.
  • Convert filesHow vivePDF turns PDFs into Word, Excel, PowerPoint, pictures, text, Markdown, HTML and EPUB, and makes PDFs from pictures, Office files, SVG and web pages.
  • Make scanned pages searchable (OCR)How to add a searchable text layer to scanned PDFs with OCR in vivePDF, manage OCR languages, scan from a scanner and clean up scans.
  • Sign and verifyHow to add a hand-drawn signature, sign a PDF digitally with a .p12 or .pfx certificate, verify signatures and create a certificate in vivePDF.
  • SecurityHow to password-protect a PDF in vivePDF, set permissions, seal it with a certificate, add watermarks and stamps, strip hidden data and redact.

Studio

  • Write a document in StudioHow to write reports, assignments and theses in the Studio document editor, with headings, tables, footnotes, references, columns and PDF export.
  • Design in StudioHow to design posters, certificates and invitations from templates in Studio, build a CV, prepare print-ready business cards, use layers and export.

Presenting

  • Present a PDFHow to present a PDF full screen in vivePDF, from F5 to the pen and laser, black and white boards, speaker notes and the two-screen presenter view.

Privacy and settings

  • Settings and privacyEvery vivePDF settings section, what Help › Privacy says goes online, and how to remove the data kept on this computer in Settings › Data.
  • Offline modeHow to turn on Offline mode in vivePDF, what it stops, what keeps working without the internet and how features show that they are off.

Reference

  • Keyboard shortcutsvivePDF keyboard shortcuts, the per-screen list that F1 opens, saving it as a PDF, the macOS key equivalents and the full list for every screen.
  • ToolsWhere to open vivePDF's 77 tools, what each of the six tool groups is for, and a searchable list with a short description of every tool.
  • Release notesThe main changes in each vivePDF version, how updates reach you and where to find the complete list of changes.
  • FAQShort answers about vivePDF's price, privacy, offline use, supported systems, signing, OCR languages and updates.
  • TroubleshootingWhat to do when a vivePDF tool fails, with the log folder, support bundle, bug reports, SmartScreen, missing LibreOffice and OCR language packs.

Developers

  • Build from sourceWhat you need to run vivePDF from its source code, how to start it in development mode, run the tests and build your own installer.
  • LicenseWhat vivePDF's AGPL-3.0 licence means for users and for anyone distributing modified builds, plus the third-party components it uses.
