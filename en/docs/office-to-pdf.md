# Convert Word, Excel and PowerPoint to PDF

> How to turn Word, Excel, PowerPoint and other Office files into PDFs with vivePDF, convert several files at once and set up LibreOffice.

URL: https://vivepdf.com/en/docs/office-to-pdf/
Last updated: 2026-10-24

To turn a Word, Excel or PowerPoint file into a PDF, open **Tools › Convert**, choose **Office → PDF** on the left, add the file and click **Convert**. LibreOffice does the Office conversion; if it is not on your computer, vivePDF offers to set it up.

1. Open **Tools › Convert** and choose **Office → PDF** in the list on the left.
2. Choose .docx, .xlsx, .pptx, .odt and similar files with **Add files**, or drag them onto the window. You can add more than one.
3. Rename the **Output file** if you like; **Browse** picks another folder.
4. Click **Convert**.

![Office → PDF selected in the Convert tool: agreement.docx in the list, Paper size and the output file](https://vivepdf.com/shots/en/office-1-1600.webp)

The result panel shows the page count and a preview of the first page. Under **Next step** you can compress the PDF or run OCR on it straight away.

![Conversion finished: a preview of the 2-page PDF and agreement-word.pdf](https://vivepdf.com/shots/en/office-2-1600.webp)

> **LibreOffice is set up once**
>
> LibreOffice is free. If it is missing, vivePDF opens its download page from the **LibreOffice is needed** window, and the conversion carries on once it is installed. TXT, Markdown, HTML, EPUB, XPS and pictures convert without LibreOffice; **Paper size** applies to those files.

A quicker way: right-click the Office file in Finder or Explorer and choose **Open With › vivePDF**. It opens as a PDF copy, which you keep with **Save as PDF…**. More on the [Convert files](https://vivepdf.com/en/docs/convert/) page.
