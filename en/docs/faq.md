# FAQ

> Short answers about vivePDF's price, privacy, offline use, supported systems, signing, OCR languages and updates.

URL: https://vivepdf.com/en/docs/faq/
Last updated: 2026-10-18

Here are the questions people ask most often about vivePDF, with short answers. If yours is not here, have a look at [Troubleshooting](https://vivepdf.com/en/docs/troubleshooting/).

## Is vivePDF free?

Yes, vivePDF is completely free. Every tool is included, and there are no paid tiers, accounts or usage limits.

## Are my files uploaded to a server?

No. Your documents, passwords and certificates never leave your computer; all the work happens on it. Help › Privacy lists every case in which the app goes online.

## Does it work without an internet connection?

Yes, the tools do not need an internet connection. Only things such as update checks, downloading language packs or turning a web page into a PDF go online. Offline mode in Settings › Web stops all of those connections with one switch.

## Which operating systems does it run on?

Ready-made installers are available for Windows 10 and Windows 11 (64-bit) and for Macs with Apple silicon on macOS 14 Sonoma or later. On Linux, vivePDF is built from source.

## Is vivePDF open source?

Yes. All of the source code is published on GitHub under the AGPL-3.0 licence. You can read it, build it yourself and change it.

## Can I edit the existing text in a PDF?

Yes. In Edit › Edit text, click a run of text on the page to change its text, size or colour. The new text is written in the document's own font at the same size; if it does not fit, it is shrunk and you are told.

## Can I sign a PDF with a digital certificate?

Yes. Tools › Sign applies a PAdES signature with your .p12 or .pfx certificate and also verifies signed files. If you have no certificate, vivePDF can create a self-signed one; it proves the document has not changed, but legal validity needs a qualified e-signature.

## Which languages can OCR read?

Turkish and English come with the app. Packs for about 40 languages can be downloaded in Settings › Tools › OCR language packs; each is downloaded once and then works offline.

## How do I update vivePDF?

The app checks for new versions itself and asks before downloading anything. To check by hand, click Check for updates in Settings › Updates, then choose Download and install and Restart.

## Does it collect usage data or telemetry?

No. vivePDF collects no usage data, identifiers or crash reports, and it does not ask you to create an account. Bug reports are never sent automatically either.

## Where do I report a bug?

Help › Report a bug opens a report window where you can copy the report, save it to a file or open it as a prefilled GitHub issue in your browser. Nothing is sent automatically, and you can also go straight to the Issues section of the vivePDF repository on GitHub.

## Which languages is the interface available in?

The interface comes in eight languages: Turkish, English, German, French, Spanish, Italian, Brazilian Portuguese and Arabic. Arabic is shown right to left.
